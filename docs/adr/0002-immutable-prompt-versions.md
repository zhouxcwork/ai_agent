# Prompt 模板版本不可变且不支持删除

---
status: accepted
---

模板迁移到数据库并提供管理页面后，最直接的做法是允许编辑和删除记录。我们决定 (name, version) 唯一且永不可变：页面上的"修改"是创建新版本，也不提供任何删除入口。原因：正在被调用方使用的 (name, version) 一旦被原地改写，线上行为即隐式变化且无法回溯；而 trace 只记录模板名和版本号（不建外键），可变的模板会让历史 trace 无法解释。

## Consequences

- 线上升级模板 = 调用方显式改版本号，行为变化可审计
- 模板表只增不减；废弃模板靠新版本替代，存储成本可忽略
- 管理接口没有 DELETE，重复创建同版本返回 409
