# 档位路由：调用方只选 fast/smart，不指定具体模型

---
status: accepted（actual_model 透出部分被 ADR-0015 取代）
---

OpenAI 协议的 model 字段通常承载具体模型名。本网关把它封装为**档位**：合法取值只有档位名（默认 fast / smart），具体模型由网关根据档位配置（供应商 × 模型 × 权重 × 健康度）自动选择。理由：模型选型是网关的治理职责——调用方表达"要快"或"要强"，供应商切换、价格优化、故障切换都对调用方透明；开放指定具体模型会让这些治理动作全部失效。actual_model 以 `供应商/模型` 格式经扩展字段透出，可观测性不损失。

## Considered Options

- 开放具体模型名（+别名映射）：调用方灵活，但供应商/模型变更需要所有调用方改代码
- 档位路由（选定）：治理集中，档位语义稳定；新增档位或调整候选不动调用方

## Consequences

- 传具体模型名（model="gpt-4o"）返回 400 `unknown_mode`，与"透传网关"行为不同，需在 README 说明
- 档位集合与候选池完全由 config.yaml 定义，档位配置错误 = 对外故障，配置变更是高危操作
- 与 ADR-0004 叠加：响应 model 字段回显档位名，actual_model 是路由目标
