# AI Agent 全栈工程师训练营\-作业四

本次作业共两道题。沿用课程中的 `login_demo` 登录会话项目：第一题解决“换一个会话以后，Agent 怎样复用已经确认的项目知识”；第二题解决“资料变多以后，怎样找到回答需要的证据”。



## 第一题：为 pi 增加项目长期记忆

记忆至少支持四个动作：写入、按项目查找并读取、更新、删除。可以由工具或课程插件提供，不强制使用特定工具名称，不要求接入向量数据库。



验证步骤

1. 把记录真正写入持久化存储

```Shell
读取当前项目的会话测试文件和测试说明，将测试路径和运行命令保存到项目长期记忆，附上来源。返回实际保存路径。
```

2. 关闭会话，启动全新会话，验证读取和核对记忆。

```Shell
从当前项目长期记忆中查找会话测试入口，再核对当前文件是否存在。
```

3. 制造一次项目变化，更新旧记录。

```Shell
将会话测试迁移到 tests/auth/test_session.py，同步修改测试说明，运行新测试命令。根据实际结果更新原来的长期记忆。
```

提交可运行代码和三张截图：建库结果、查询对比与回答、更新后的回答。



## 第二题 基于 LlamaIndex 实现向量与关键词混合检索 RAG

1. **建立索引**：读取资料并分块，建立向量与关键词索引，展示分块内容及来源。

```Shell
使用 Python 和 LlamaIndex，读取当前项目的登录资料并分块，基于同一批节点建立向量索引和 BM25 关键词索引。使用真实 Embedding，保存索引，输出节点数量及一条带来源的分块样例。
```

2. **查询对比**：分别用三种检索方式查询“登录会话的有效期是多少分钟？”，展示各自的前三条结果，再用混合检索生成带来源的回答。

```Shell
分别用向量、BM25 和 RRF 混合检索查询“登录会话的有效期是多少分钟？”，输出各自前5条结果及来源。再将混合检索的证据交给真实模型，生成带来源引用的回答。
```

3. **更新验证**：将资料中的登录有效期改为 20 分钟，更新两路索引，重新查询，确认答案和引用使用新资料。

```Shell
在作业资料副本中，将登录会话有效期改为 20 分钟，同步更新两路索引，确保旧分块退出当前检索。重新查询同一个问题，输出回答及引用的新资料。
```

提交代码和三张截图：建库结果、三路查询对比与回答、更新后的回答。
